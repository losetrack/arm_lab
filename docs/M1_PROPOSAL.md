# M1 场景与判定参数（已确认）

用户已确认采用本表作为 M1 开发参数，已落实到 [configs/mvp.yaml](../configs/mvp.yaml)。M1 检查结果见 [M1.md](M1.md)。这些参数不代表抓放策略或正式成功率验收已经通过；变更需讨论，不能在测试失败后静默放宽。

世界坐标单位为米，桌面中心为 x=y=0。

| 项目 | 已确认参数 |
| --- | --- |
| 桌面 | 复用 Lift：0.8×0.8×0.05，桌面高度 0.8；摩擦三元组 (1, 0.005, 0.0001) |
| 方块 | 单个纯红色无纹理方块，边长 0.04、质量 0.1 kg；摩擦与桌面相同 |
| 初始位置 | 中心 x∈[-0.10, 0.10]、y∈[-0.15, -0.05]；底面初始距桌面 0.01，复用上游落下初始化方式 |
| 朝向 | 绕竖直轴均匀采样 [-15°, 15°] |
| 目标区域 | 中心 (0.10, 0.15)，0.12×0.12 正方形；使用绿色 site 标记，没有碰撞实体；初始方块与区域的平面边界间距至少 0.03 |
| 固定抓取姿态 | 使用已诊断的 xyzw=(√0.5, √0.5, 0, 0)，控制点 z 轴向下 |
| 相机 | 复用固定 agentview：位置 (0.5, 0, 1.35)，MuJoCo wxyz=(0.653, 0.271, 0.271, 0.653) 归一化；实测继承的垂直视角为 45°，已显式记录；256×256、20 Hz |
| 深度渲染 | 关闭离屏 MSAA，避免 M0 已测得的深度亚像素采样偏差；RGB-D 使用同一渲染设置 |
| 放置判定 | 方块 8 个顶点投影全部位于目标边界内，底面距桌面不超过 0.003；已下发打开夹爪指令且无夹爪—方块接触 |
| 稳定判定 | 线速度范数≤0.01 m/s，角速度范数≤0.1 rad/s，所有成功条件连续保持 1 秒 |
| 回合时限 | 60 秒仿真时间；阶段超时与抓取状态机在 M2 单独讨论 |
| 开发种子 | 0–9；正式 50 个测试种子另行锁定，开发阶段不使用 |

颜色阈值、有效深度范围在 M3 根据已确认场景的图像讨论；记录预算、视频参数在 M4 实测后讨论。NVIDIA 加速排查不属于这组场景参数的批准范围。
