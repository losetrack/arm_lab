# M2 专家闭环参数（已确认）

M1 已完成。M2 复用已确认的场景、T03 控制上限和成功判定，只增加真值定位器与共享抓取状态机。用户已确认以下开发起点，并授权自行确定可调整、不影响整体范围的参数。已按本表实现并通过开发种子检查，详见 M2_M3.md。

| 项目 | 建议 |
| --- | --- |
| 初始化 | 打开夹爪并等待 1 秒，让方块完成初始落下，再获取目标位置 |
| 接近 | 保持固定俯视姿态，到方块中心上方 0.12 m；阶段上限 15 秒 |
| 下降抓取 | 控制 site 到方块中心高度；阶段上限 10 秒 |
| 移动动作 | 每轴采用目标与当前位置之差，限幅到已确认的 ±5 mm；到达判据为三维位置误差范数≤3 mm |
| 夹取 | 发送闭合指令并等待 1 秒；两指关节位置绝对值之和处于 [0.01, 0.065] m 才继续，否则标记 `grasp_failed`；阶段上限 2 秒 |
| 抬升 | 回到抓取中心上方 0.12 m；阶段上限 10 秒 |
| 搬运 | 保持抬升高度，移动到目标区中心上方；阶段上限 15 秒 |
| 放置下降 | site 到桌面高度+方块半边长+0.005 m（本场景为 0.825 m）；阶段上限 10 秒 |
| 释放 | 打开并等待至少 0.5 秒，两指间距达到 0.065 m；阶段上限 2 秒 |
| 撤离 | 保持夹爪打开，竖直返回抬升高度；阶段上限 10 秒 |
| 等待判定 | 最多 3 秒，复用 M1 连续稳定 1 秒的成功条件；未成功标记 `not_in_target` |
| 全局限制 | 保持 M1 的 60 秒回合上限；阶段上限是各自最大值，不保证它们全部相加仍可执行完；不自动重试 |
| 验证 | 先单个开发种子排查，再使用已确认的 0–9；保留每次实际结果，不读取正式测试种子 |

两指间距来自机器人状态，视觉策略也可合法读取。上述间距条件只是夹持启发式，不证明物体被抓住；物体真值只由专家定位器与独立评测通道读取，不能成为共享状态机对视觉策略额外提供的输入。

M2 不放宽 M1 成功判据或修改场景。已获授权在 0–9 开发种子上调整控制参数并记录依据；本次无需修改这些参数。改变整体任务、场景范围或验收条件仍需单独讨论。
