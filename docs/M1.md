# M1 基础框架检查

本页记录 M1 阶段交付：配置入口、场景、后端生命周期和任务判定。后续抓取策略、记录及正式验收已完成，见 [M5.md](M5.md)。参数依据为用户确认的 [M1 参数表](M1_PROPOSAL.md)。

## 实现

- `configs/mvp.yaml` 与 `config.py`：显式记录场景、相机、频率和判定条件；不支持的频率组合报错。
- `backends/scene.py`：复用 Panda、TableArena、BoxObject 和上游采样/重置逻辑。方块纯红无纹理，固定质量与尺寸；目标区域为绿色 site，无碰撞几何。离屏 MSAA 在创建渲染上下文前关闭。
- `backends/robosuite.py`：`reset(seed)`、`step(ActionChunk)`、`render()`、`close()`；重置时重建单环境，统一恢复随机源、机器人和夹爪、控制目标及判定历史。特权物体状态经独立方法提供，不混入观测。
- `tasks/placement.py`：八顶点边界、桌面距离、释放、接触、速度和连续稳定时长判定；先判成功再判 60 秒超时，终止结果保持不变。终止后继续 step 会报错，必须 reset。
- `runner.py`：命令行场景检查。只保持末端并打开夹爪，不运行策略；仅输出终端结果，不创建实验记录。`running` 表示检查步数已用完而任务尚未终止。

## 验证

环境沿用 M0 的 Python 3.10.21 / robosuite 1.5.2 / MuJoCo 3.3.0。

- 20 项单元测试通过，覆盖动作与观测契约，以及完整入区、旋转后越界、桌面距离、运动速度、夹爪释放、接触、稳定计时重置和超时等边界。
- 2 项 MuJoCo 集成测试通过：开发种子 0–9 及重复 seed=0 的初始化，固定尺寸/质量/视角、MSAA=0、256×256 RGB-D、不同种子不同位姿、相同种子精确复现、零实验文件、物理放置后的稳定成功、终止后拒绝 step、重置和超时。
- 原生窗口完成 seed=0 的 100 个控制步（5 秒仿真），正常退出。
- 集成测试将方块直接置于目标区域，用于检查物理状态与判定器连接。这不是机械臂抓放成功，不计入策略成功率。
- 集成测试的快速超时检查只缩短测试对象的时限；生产配置仍为 60 秒，单元测试单独验证 60 秒边界。

运行命令见 [README](../README.md)。集成测试显式选择 `-m integration`，日常默认只运行快速测试。

## 限制与后续

当前仍为 llvmpipe 软件渲染，没有完成 NVIDIA 图形加速验证。M0 的一次深度越界未在本轮重置和运行检查中复现，但不宣称其根因已经解决。

M2 将实现真值专家与共享抓取状态机；新增高度、到达阈值、夹爪阈值及阶段超时先按项目规范确认。M3 视觉、M4 记录和 M5 正式验收尚未开始。本轮未推送远端或合并主分支。
